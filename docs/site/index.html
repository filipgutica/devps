devps

What is running, who started it, and how to stop it.

devps manages local dev servers on macOS. It shows one row per job, with ports, project, origin, and age. Jump back to where a server started, open its URL, or stop the whole job.

$ brew install filipgutica/tap/devps

Homebrew installs Python and fzf. Without fzf, or outside a terminal, devps prints a plain table. New to Homebrew? Install it first.

On screen

PORTS
Every port the job listens on.
PROJECT
Repository, then [worktree] and subfolder when they differ.
COMMAND
The runner, such as pnpm dev.
ORIGIN
The terminal, editor, or agent that started it. ⚠ orphaned means that launcher is gone.
AGE
How long the job has been running.
PID
The job's root process.

Commands

A port matches first, then a job's root PID or a listener PID.

  • devps

    Open the interactive picker.

  • devps ls

    Print the plain table.

  • devps jump 5173

    Focus the terminal, editor, or agent app that started the server.

  • devps open 5173

    Open http://localhost:5173 in the browser.

  • devps kill 5173

    Stop the whole job after you confirm. Add -y to skip the question.

  • devps --all

    Include every TCP listener, not only dev runtimes.

Keys in the picker

The header line in the picker lists these too.

  • Enter

    Jump to the selected server's origin.

  • Ctrl+O

    Open its URL in the browser.

  • Ctrl+X

    Stop the selected jobs after confirmation.

  • Tab

    Select several jobs.

  • Ctrl+R

    Refresh the list.

Where jump lands

Exact tab or pane selection depends on the origin information available.

OriginJump target
Warp, iTerm2, Terminal, tmuxThe tab or pane, when the matching session information is available.
VS CodeThe window for that folder. It cannot select the terminal tab.
Codex app, T3 Code Workbench, Claude appThe app. It copies codex resume <id> or claude --resume <id> when the session is known.

Good to know

Stop is careful. devps sends SIGTERM to the job root and its children, then SIGKILL to survivors after three seconds. It protects GUI apps, PID 1, and the terminal or agent that runs devps.

Only a fixed list of environment variables is read. To find the origin of an orphaned job, devps reads hints such as WARP_FOCUS_URL and CODEX_THREAD_ID. It does not print, store, or pass on other values.

The default filter can hide compiled servers outside your home directory. Use --all to include every TCP listener.

macOS only. devps uses macOS ps, lsof, open, osascript, and pbcopy. Some origins support app focus only, so it cannot always return to an exact tab or conversation.
